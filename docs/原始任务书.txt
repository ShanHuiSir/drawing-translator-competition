题目：英文零件图纸术语自动翻译功能

项目任务概述
基于 Python 制作一个应用（需包含UI界面），识别机械图纸中的英文术语并自动翻译为中文。
项目目标
项目内容主要包括以下三点：
1）可以识别图纸中所有的英文文本内容；
2）识别完英文内容后，需在后台存储该文本内容的坐标，以及其翻译后的中文内容；
3）将翻译内容生成在图纸上（翻译内容以红色字体显示，可挑选遮挡与不遮挡被翻译英文内容的功能）。

项目需求
模块功能、性能要求
具体功能与性能要求如下：
核心功能要求
（1）图像与文档解析能力（前置要求）
系统应能原生读取并准确解析主流二维图像及文档文件格式，包括 .pdf（图像型/扫描件）、.jpg、.png 及 .bmp。需具备高精度 OCR（光学字符识别）与图像预处理能力，完整提取图像中的文本区域、文字内容及位置信息（如文本边界框坐标）进行处理，确保文字识别无丢失、位置定位无错位。支持处理不同分辨率、不同旋转角度及不同背景复杂度的图像文件，为后续翻译与标注提供准确的数据基础。

（2）英文术语识别与翻译（核心任务一）1）自动识别并定位图纸中所有的英文文本内容。
2）识别能力需覆盖不同字体、不同大小、不同旋转角度的文本对象。
3）具备良好的抗干扰能力。
（3）信息存储与坐标提取（核心任务二）对于每个识别出的英文文本，准确提取其位置信息。
1）精确输出该文本对象在图纸上的坐标（如左下角点 MinX, MinY 和右上角点 MaxX, MaxY）。
2）同时，记录该文本对应的翻译后的中文内容，并以结构化数据（如 JSON）的形式进行存储。
（4）翻译功能补充（核心任务三）
1）翻译内容须以红色字体显示。
2）提供功能选项，可选择遮挡或不遮挡被翻译的英文原文内容。

性能与可靠性要求
1）检测精度：在甲方提供的标准测试集（≥50 份包含不同格式、不同内容的零件图纸样本）上，翻译准确率 ≥ 95%
2）处理效率：单图纸文本提取与翻译总耗时 ≤ 5 秒（测试环境：Intel Core i7 / 16GB RAM / SSD）。
3）兼容性：支持 Windows 10/11 操作系统。
4）稳定性：连续运行 72 小时无内存泄漏或崩溃；对损坏的文件应弹出友好提示而非程序异常退出。
5）安全性：所有图纸数据仅在本地处理，不得联网传输；操作日志记录检测时间、文件名、问题统计，保留 ≥180 天。
