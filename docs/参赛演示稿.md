# 参赛演示稿（约 4 分钟）

**开场 20 秒**：这是“图译”，一个基于 Python 的本地机械图纸英文翻译工作台。英文文本、识别坐标和中文译文一起保存，运行过程中不上传图纸。

**启动与导入 30 秒**：双击图译.exe，打开本地界面。导入 PDF 或图片，可指定页码。这里使用提供的防跳屑结构图，演示不是静态页面，图纸、译文和坐标都可编辑。

**识别与定位 50 秒**：图左侧为英文原图，右侧为红色中文预览。选择 GROOVE DEPTH，左图自动定位，右侧显示“槽深”及 MinX/MinY/MaxX/MaxY。PDF 为 pt，图片为 px。旋转和多页均按实际显示页记录。

**专业译文与复核 50 秒**：精确术语优先采用本地词库，其余英文使用本地机器翻译。打开待复核筛选，现场修订一条译文，保存并加入个人术语库。强调专业人员复核机制，不声称通用机器译文天然达到 95%。

**两种模式与导出 45 秒**：切换不遮挡与遮挡模式，展示红字与原文的关系。中文框过小时，遮挡原文并移到空白区，实际标注坐标也会记录。下载结果 ZIP，展示 PDF、坐标 JSON 和 CSV。

**验证与交付 35 秒**：展示功能测试报告和六份 139 页实际输出。说明 Windows 免安装包、完整可编辑源码、技术文档和复测脚本都已提供。准确率、时效性能与 72 小时指标将按甲方标准集和规定 Windows 环境正式验收，展示实测值而不虚报。
