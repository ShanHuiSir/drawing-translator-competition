# 使用手册

## 导入与处理

支持 PDF、JPG/JPEG、PNG、BMP，单文件上限 250 MB。PDF 可为扫描件、文字对象或混合页，也支持多页。对加密、损坏、空文件和不支持格式，界面会给出提示并继续接受其他文件。

快速模式处理当前显示方向，适合常规水平图纸；增强模式使用四方向识别、白纸对比度增强和重叠切片，适合竖排文字、浅色文字和小字截图。增强模式耗时更长，低分辨率原图中已经丢失的笔画无法保证恢复。

可一次导入多个文件，任务依次处理，降低同时加载模型的资源占用。工作台显示实际页级进度，可取消任务；取消在当前 OCR 步骤结束后生效。已完成任务和修订结果在关闭程序后继续保留。

## 翻译复核

右侧可筛选全部、待复核或术语匹配。搜索框匹配英文和中文。点击条目，左图以框选方式定位原文，并显示坐标及单位。可以修改错误的英文 OCR 原文、修改译文、关闭该条标注，或将已确认词条加入个人术语库。保存快捷键为 Ctrl/Command + Enter。

术语库精确匹配优先。数字模板保留尺寸和公差；未匹配文本使用本地神经翻译。通用模型译文、模板组合和低置信度 OCR 会标为待复核；图号、尺寸和短编码保留，不强制翻译成中文。

“已复核”表示使用者已按下保存按钮，不代表自动获得工程认证。翻译结果只用于阅读辅助，应以原图尺寸和正式技术要求为依据。

## 红色标注

不遮挡模式寻找不与原文、其他文字或绘图笔画重叠的空白区域。优先放在附近，必要时移到其他空白区；实际标注位置保存在导出 JSON 的 `export.pages[].placements`。

遮挡模式在原文区域叠加白色遮罩并绘制红色中文。中文较长而原文框过小时，为保持可读字号，仍遮挡原文，但将译文移到空白区并记录提示。PDF 原文对象保留在遮罩下，源文件始终不被改写。

若页面确无可用位置，不强行覆盖工程图线，导出会显示未放置数量，该条内容仍完整保存在 JSON/CSV。交付的 139 页快速样例最终结果中，两种模式均为 0 条因布局空间不足而未放置。

## 导出与原图保真

下载 ZIP 内有译文图纸、坐标 JSON 和 UTF-8 BOM CSV。PDF 保持页数、显示页尺寸、图像流和矢量对象，不将整页转为图片。只处理指定页时，其他原始 PDF 页仍保留在导出文件中。

JPG 导出为无损 PNG，避免二次 JPEG 压缩；PNG 保持原像素尺寸，BMP 输出 BMP；CMYK 位图导出无损 TIFF 并保留色彩模式。灰度图无法在原灰度色彩模型中表示红色，因此输出 RGB，原灰度像素保持等值 R/G/B，JSON 中明确记录这种必要转换。EXIF 方向统一为实际显示方向，文件原件不变。

## 文件位置与恢复

`workspace/jobs/<任务ID>/source` 为上传副本，`result.json` 为可编辑结果，`exports` 为标注导出。`workspace/glossary.json` 为个人术语库，`workspace/logs` 为操作日志，`workspace/cache` 为提取缓存。应用不自动删除日志；请保留工作目录以满足 180 天留存要求。

如果 Windows 启动失败，先确认完整解压、目录可写，再运行“启动图译.bat”读取控制台错误。原生 exe 的启动日志在同目录 `startup.log`。模型缺失时会提示通用模型未安装；不应删除 `models` 或 `python` 文件夹。

退出使用左下“退出工作台”。退出不删除数据；单独关闭浏览器页面，后台仍会继续处理队列。
