# 技术方案与关键算法

## 模块边界

`extraction.py` 统一 PDF / 位图读取、OCR 与坐标；`translation.py` 负责术语库、尺寸模板和离线模型；`exporting.py` 负责排版、红字和证据导出；`pipeline.py` 串联处理、缓存、日志和计时；`service.py` 提供本地 UI 接口；`web` 提供双栏预览、定位、复核和下载；`launcher.py` 仅绑定回环地址并打开浏览器。

UI 全部资源从本机提供，不使用 CDN、在线字体或第三方脚本。Windows 版使用官方 CPython embeddable 和 Windows 二进制轮子，C 启动器只启动本地 `pythonw.exe`。启动器源代码和交叉编译参数一并提供。

## 英文识别

先读取 PDF 原生文字对象。若页面存在覆盖明显面积的扫描图，即使有少量原生文字层，也追加 OCR，防止仅识别标题而漏掉扫描内容。对纯位图直接 OCR。英文专用 PP-OCRv3 检测/识别模型比通用中文模型更适合窄体与宽字距工程字。

OCR 临时图采用等比例渲染；白纸背景对比度增强只作用于临时识别图。增强模式对低分辨率位图进行有界放大，切为 1700 像素重叠窗口，在 0/90/180/270 度分别检测。重叠检测按框交并关系与置信度去重，保留原始多边形。

旋转恢复先扣除切片偏移，再通过直角旋转逆变换恢复原显示图坐标。例如逆 90 度旋转为 `x = W - y'，y = x'`。最后以实际渲染宽高映射回 PDF pt 或图片 px。JSON 同时提供左上角 bbox 与左下角 MinX/MinY/MaxX/MaxY，避免坐标口径混淆。

## 离线翻译

匹配不依赖文件名、页码或样例坐标。工程术语库对大小写、标点和 OCR 粘连空格规范化。精确词条优先，数字模板处理“见第几页”“数量几处”等稳定表达；全词条覆盖的短语保留原数字组合。

其余行由 Argos/OPUS 英中模型在 CTranslate2 CPU int8 上本地生成。识别文本不发送给 DeepSeek 或其他网络接口。数字和公差若在神经译文中发生变化，按数字分段重译并附复核提示。OCR 本身把字母 O 误读为数字 0 等问题，需要人工核对原文；本系统不偷偷修正工程尺寸。

专业语义与通用自然语言翻译不同，如 LAND 在本任务中表示直壁段。术语库可由工程人员在 UI 中持续补充。不能把通用模型输出的“流畅”当作专业准确性证明，因此神经译文保留待复核状态。

## 保真导出与布局

PDF 原始矢量、扫描流和显示页几何直接保留，只追加中文字体与红字层。不进行代价可能为二次方的完整对象去重：附件中一份 CAD PDF 有 275,042 个 xref 对象，这一选择避免长时间保存卡顿。中英文混排使用同一内嵌字体测量和绘制，避免 PDF 内置 CJK 字体拉丁字宽差异引起越界。

不遮挡布局使用灰度笔画积分图，常数时间检查候选区域是否有暗像素，同时避开所有原文框及已放置译文。附近候选无解时，按离原文距离排序搜索其他空白区；原文坐标和译文实际坐标分别存储。积分图来自降采样预览，极细线仍建议放大复核。

## 可靠性与安全

模型推理串行，文档逐页处理，翻译缓存上限 5000 条。资源通过上下文管理关闭；缓存仅存提取内容，术语库更新在下一次处理生效。结果和术语库采用临时文件加原子替换。

服务只绑定 `127.0.0.1`，校验 Host 与 Origin，并要求本进程随机令牌进行上传、编辑、导出和退出。文件扩展名、实际解析、体积、像素量、页码范围分别校验。操作日志按日 JSONL 追加，不自动删除。

已定位并规避 OpenCV 5.0.0.93 在特定尺寸缩放上的原生崩溃；发行固定 OpenCV 4.11.0.86，并以真实图纸子进程测试覆盖原触发路径。该修复不等于 72 小时稳定性已获验收。

## 可复现验收

功能测试覆盖四种格式、四方向、混合 PDF、坐标、原件完整性、红字、复核持久化、日志、损坏文件与本地访问保护。`scripts/evaluate.py` 独立统计 OCR 召回率、已识别术语译文正确率和联合通过率，支持添加期望坐标进行定位对比。完整验收须由甲方提供独立至少 50 份图纸及人工金标。

稳定性脚本 `scripts/soak_test.py` 默认 72 小时，持续记录实际运行时长、错误和 RSS，禁用 OCR 缓存。不能以短时自检或静态源码检查代替已完成 72 小时测试。
